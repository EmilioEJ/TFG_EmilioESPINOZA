  {Abstract}
  {This Curricular Integration Project addresses the limitations of current document repositories and institutional interfaces in disseminating academic information, which lack semantic search capabilities and proactive interactivity, leading to delays in routine student queries and administrative overload in administrative offices. Aiming to develop a prototype of an intelligent virtual assistant with a 3D avatar interface and computer vision for the dissemination of academic regulations and curricula, the Design Science Research Methodology (DSRM) was adopted in combination with the agile Scrum framework for iterative software development. The proposed hybrid architecture implements visual capture via bounding boxes and 3D graphic rendering using WebGL locally on the client device, while a local server orchestrates a Retrieval-Augmented Generation (RAG) engine utilizing the multilingual embedding model alongside the local Nemotron model. The main results demonstrate high semantic accuracy, achieving a Hit Rate of 92.0\% in academic regulation retrieval, an average Time to First Byte (TTFB) response time of 450 ms ensuring conversational fluency via WebSockets, and a positive usability evaluation with 13 students regarding integration, accuracy, and usage preference. In conclusion, the decentralized architecture and the use of generative artificial intelligence provide a viable, robust solution that transforms traditional, static queries into an interactive, accessible, and efficient support channel for the university community.}
